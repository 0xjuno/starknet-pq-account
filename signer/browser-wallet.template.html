PQ account signer

Sign a Starknet Sepolia transaction in this browser with BOTH a STARK-curve ECDSA key and a Falcon-512 key, derived from one 24-word mnemonic. The account was migrated in place from an OpenZeppelin account.

Testnet only. Experimental and unaudited. Keys are derived in this tab and never sent anywhere; the mnemonic is not stored.

1. Restore keys from the mnemonic
Account
ECDSA public key
Falcon key (first felt)
On-chain check
2. Send 0.01 STRK

The transaction hash is signed twice here: ECDSA (2 felts) and Falcon-512 with the standard SHAKE-256 hash-to-point (60 felts). The account accepts it only if both verify.
